# Offer configurable subtitle muxing

Anime365 subtitle translations may expose a separate styled ASS file alongside the MP4. When `ffmpeg` is installed, a365dt offers one batch-wide muxing choice unless Download preferences enable it without confirmation; MP4 is the default Mux container, stream-copying video and audio while converting ASS to `mov_text` for playback compatibility, and configurable MKV preserves ASS styling by stream-copying every track. The selected container applies only when a separate Subtitle asset needs muxing; already self-contained MP4 files remain unchanged. When `ffmpeg` is unavailable, downloading continues with separate files even when muxing was explicitly requested.

An MP4 mux stages its source as `.video.mp4` so interruption and completion remain distinguishable across platforms. After a successful mux, a365dt removes the source video and ASS; after a failed mux, it reports the failure, removes only the incomplete output, and preserves `.video.mp4` with `.ass`. MKV retains the same success and failure guarantees without requiring a distinct source name.
